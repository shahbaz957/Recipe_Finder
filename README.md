# 🍽️ Recipe Finder App

A modern, responsive **Recipe Finder** web application built using **React**, **Redux Toolkit**, and **Tailwind CSS**.  
Search for recipes from around the world, explore their details, watch tutorials, and save your favourites — all in one elegant app.

---

## 🚀 Features

### 🔍 Search Recipes
- Search for thousands of recipes by name or ingredient.  
- Fetches data in real-time using **TheMealDB API**.

### 📜 Recipe Details
- View complete recipe details including:
  - Category
  - Ingredients
  - Instructions
  - YouTube cooking video
- Smooth scroll-to-top animation when viewing details.

### ❤️ Favourite System
- Add recipes to your **Favourites** list.
- Remove recipes easily with one click.
- Favourites are stored in **localStorage** for persistence even after reload.

### 🌐 Responsive UI
- Fully responsive layout built with **Tailwind CSS**.
- Elegant animations and hover effects for a premium feel.

### ⚙️ State Management
- Centralized global state management using **Redux Toolkit**.
- Async fetching handled via **createAsyncThunk**.
- Data caching and reactivity across components.
